# Progress

## Building Part 1

The first part will be building a simple sump of volume 30 L, so that the pump flow rate 500 ml/min cycles the water once per hour.

### Equipment list:

- [x] Soldering iron, helping hands, solder, desoldering pump and sandpaper
- [x] Mains to DC converter (SMPS), 230 V AC to 24 V DC, 2 A ([Tiger Power Supplies via CPC Farnell](https://cpc.farnell.com/tiger-power-supplies/tp2448/uk-mains-ac-dc-power-supply-24v-dc-2a-48w-25mm-dc-plug/dp/PW05878))
- [x] DC barrel jack adapter (2.5 mm x 5.5 mm) ([AliExpress](https://www.aliexpress.com/))
- [x] Peristaltic pump, 24 V DC, 500ml/min, 1.4 A ([AliExpress](https://www.aliexpress.com/))
- [x] PharMed BPT Tubing (6.4 mm x 9.6 mm) ([AliExpress](https://www.aliexpress.com/)) - may need more of this

### Electronics list:

- [x] Arduino Uno WiFi Rev 2 and Arduino Uno Mega
- [x] Buck Converter, LM2596, 3 A ([AliExpress](https://www.aliexpress.com/))
- [x] MOSFET, IRLZ44N, n-channel logic level enhancement mode
- [x] Flyback diode, 1N4001
- [x] Resistors, 100 Ω and 10 kΩ
- [x] Capacitors, 100 nF (ceramic) and 220 μF (electrolytic) [omitted for now]
- [ ] Level sensor (ultrasonic?) [got an ultrasonic sensor but not waterproof]
- [ ] Float switch
- [ ] PCB breadboard
